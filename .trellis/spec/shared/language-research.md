# 科研语言表达

## 启用条件

仅在项目语言规范声明适用于当前科研文类时启用；文件随 Registry 分发不等于默认适用于所有仓库。与[通用语言表达](language-general.md)配合使用；学科定义、投稿要求、数据和文章合同由项目维护。

## 论证与证据

- 交代研究对象、方法、条件和比较基准；结果写清观察，解释与观察区分，结论强度与实际证据相符。
- 直接证据支持的结果明确陈述；条件性结果保留条件。不得用模糊词掩盖证据缺失，也不得把有限结果扩大为普适规律。
- 保留科学否定结果、必要定义、适用条件与不确定性。语言整理不能改变因果关系、数据、单位、统计含义或引用所支持的命题。
- “显著 / significant”须按语境区分统计显著性与变化幅度；统计检验的指标、阈值和结果归文章定义。翻译不得把“明显变化”自动升级为统计显著。
- 方法、观察、解释和意义之间保持可追溯关系。摘要概括目的、方法、主要结果和结论；结果与结论避免逐图复述或压缩成数据清单，具体结构遵守文类要求。

## 双语和回归

- 中英文核对变量、条件、数值、单位、否定、比较对象和论断强度；术语先核对定义，再选择对应词。相同拼写不保证相同概念。
- 技术修改之后重查受影响段落及上下文；全文语言交付还须核对最新读者载体中的图表文字与生成文字。自动搜索和文本提取用于定位，不能替代语义与页面检查。
- 既有作者或文章规则与上述要求冲突时，记录原条款、范围和冲突，交由有效优先级或明确裁决处理。本文件不授权删除旧规则、隐去影响判断的信息或将旧争议推广到其它项目。
