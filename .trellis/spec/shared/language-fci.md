# FCI 概念与双语术语

## 启用条件

仅在项目声明涉及燃料—冷却剂相互作用（fuel–coolant interaction, FCI）且采用本规范时启用。下表约束该领域语境中的概念对应，不替代文章的数学定义、模型说明或原始文献正式名称。

| 概念 | 中文表达 | 英文对应与适配边界 |
|---|---|---|
| 爆炸前熔融物与冷却剂混合阶段 | 粗混合 | premixing；不把其它学科的 premixing 自动改为粗混合 |
| 射流整体解体及其长度指标 | 射流破碎、射流破碎长度 | jet breakup、jet breakup length；长度判据由文章定义 |
| 模型或机理中的碎裂过程 | 碎裂、碎裂模型、水力学碎裂、热力学碎裂 | fragmentation 及其限定词须与机制定义对应；不能批量互换 breakup 与 fragmentation |
| 熔融物形成的碎片 | 碎片、碎片尺寸 | fragment、fragment size；质量或体积分数、粒径统计量由文章定义 |

- 先确认物理对象与阶段，再统一用词；同一中文词可因语境有不同英文对应，禁止机械的一对一全局替换。
- 峰值压力、压力增量、冲量、熔融物份额等量必须保留参考压力、积分区间、测点、分母及统计定义；这些定义归文章，不由短名称反推。
- 具体测点、数值、压力耦合算法名、相场译法及作者指定表达留在仓库或文章术语表。未经核定的对应标记待核定；禁止凭共享分发把局部用法变成领域通则。
