# 通用语言表达

## 适用范围

适用于面向读者的中英文说明、文档和沟通。项目声明读者、文类及专有用语；科研、领域和作者语气规则按各自启用条件另行读取。代码标识、原始引文、正式名称和受保护文本按其原有合同处理。

文档语言按读者和用途分别规定：内部维护说明、用户界面、公开介绍、发布说明与投稿材料可以采用不同语言。现有文类合同优先，不将一个目录模板的语言偏好扩展到全部文档。

## 表达

- 先明确要传达的事实、动作或判断，再按读者需要补充依据和细节。使用常见词、具体对象和直接动词；必要术语首次出现时解释。
- 句子之间建立真实的条件、因果、比较或递进关系；段落围绕一个中心展开。列表和表格用于确实便于并列、顺序或比较的内容，不为格式整齐强行拆分。
- 删除无信息增量的自我说明、空泛评价、重复总结和机械排比。需要说明差异时写清比较对象与依据，不凭禁词表删除有意义的比较。
- 直接陈述事实或动作；不引入读者未提出、也不帮助理解的替代说法来包装判断。中英文的“不是……而是…… / not X but Y”等句式按实际信息作用复核，项目既有更严格限制保持原效力。
- 用普通词和明确关系解释问题，不为普通对象自造抽象标签或复合术语。正式术语、产品名和确有定义的概念保持原名；“闭环 / loop”等词是否需要改写取决于其实际含义。
- 长短句按逻辑自然安排。拆句时保留条件与结论的归属，避免限定词堆叠，也不把完整逻辑切成碎片。

## 中英文对应与复核

- 中英文保持同一对象、动作、否定范围、比较基准和确定程度；按目标语言自然表达，不逐字搬运句法或禁词。
- 区分直接适用、需要适配、不适用和待核定。无法确认术语或改写是否改变含义时保留原文并标记待核定，不静默替换。
- 搜索只能定位候选。逐句检查实际含义，再检查段落衔接；零命中或自动评分不能证明表达合格。事实和完成声明的核验由[证据与验证](evidence-and-verification.md)管理。
